# Fiber Ops

Fiber Ops is a field-oriented fiber infrastructure management system designed for Intelligent Transportation Systems (ITS) deployments.

It provides a structured platform for tracking:
- Projects
- Cabinets
- Ground boxes
- Poles
- Fiber cables and splice topology
- Node GPS metadata
- Construction and commissioning workflows

## Purpose

Fiber Ops was created to bridge the gap between engineering design documentation, field installation realities, and long-term maintenance tracking.

It enables real-world fiber infrastructure to be digitally modeled and managed.

## Tech Stack

Backend:
- Fastify
- Prisma
- PostgreSQL

Frontend:
- Next.js
- React
- TypeScript

## Target Use Cases

- ITS fiber deployments
- Transportation corridor builds
- Smart city infrastructure
- Field engineering documentation
- Fiber splice tracking
